# Zadanie 2 – Programovacie techniky
Aplikácia v Pythone s grafickým rozhraním (Tkinter) a vizualizáciou (Matplotlib).
Program vygeneruje pole 50 náhodných hodnôt, zoradí ho vzostupne, vypočíta priemer, minimum, maximum a hodnoty podľa vzorca y = x * 1.20 + 5.

## Použité AI nástroje
Pri vývoji aplikácie, návrhu grafického rozhrania (Tkinter) a optimalizácii kódu boli použité nástroje **GitHub Copilot**, **Google Gemini** a **Claude**
